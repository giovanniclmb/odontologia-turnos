# Clinic Cloud

- **URL**: https://clinic-cloud.com/tarifas
- **Fecha de investigación**: 2026-11-17

## Problema que resuelve

Centralización de agenda y gestión de pacientes según el posicionamiento del proveedor; alcance: Clínicas generales con módulo odontológico.

## Usuarios objetivo

Clínicas generales con módulo odontológico. Proveedor: Clinic Cloud; entidad legal no evidenciada. País: No evidenciado. Modalidad: SaaS clínico.

## Features detectadas

- Agenda: Declara múltiples agendas según plan. La ayuda vincula citas y prestaciones del presupuesto. Recurso sillón concurrente: No evidenciado.
- Paciente y automatización: Declara reserva 24/7 por Doctoralia y recordatorios. WhatsApp de Doctoralia Pro tiene condiciones propias; no atribuirlo como incluido automáticamente.
- Clínica: Historia clínica y odontograma en Max declarados; ayuda documenta presupuesto desde odontograma. Periodontograma: No evidenciado.
- Administración: Caja, presupuestos, liquidaciones y reportes; facturación TicketBAI/VeriFactu, que no prueba facturación ARCA.
- Integraciones: Doctoralia declarado. Mercado Pago, obras sociales argentinas, Google Calendar y API pública: No evidenciado.
- Seguridad y portabilidad: Permisos por niveles declarados. Exportación, auditoría, cifrado y política de backup: No evidenciado en las fuentes examinadas.

## Pricing

Mini 29, Pro 49 y Max 79 EUR/mes + IVA; Enterprise a convenir. Odontograma en Max. Apertura actual muestra 50% de descuento durante 3 meses, no 2. Agendas adicionales +10 EUR según límite del plan.

## Posicionamiento

SaaS clínico para clínicas generales con módulo odontológico. No se adopta el posicionamiento comercial como validación de resultados.

## Diferenciadores

Aspectos observables para contrastar: No comparar Mini como si incluyera odontograma. Precios y promoción están sujetos a contratación; no se abrió cuenta ni aceptó términos.
