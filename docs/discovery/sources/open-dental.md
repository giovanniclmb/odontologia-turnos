## Problema que resuelve

Centralización de agenda y gestión de pacientes según el posicionamiento del proveedor; alcance: Consultorios y clínicas; referencia de dominio internacional.

## Usuarios objetivo

Consultorios y clínicas; referencia de dominio internacional. Proveedor: Open Dental Software. País: EE.UU., domicilio en Salem, Oregon. Modalidad: Self-hosted; cloud publicado para EE.UU..

## Features detectadas

- Agenda: Manual documenta operatorios, profesionales, vistas, bloqueos y manejo de citas. Permitir superposición es configurable: no atribuir una prohibición universal.
- Paciente y automatización: Web Sched y recordatorios tienen servicios y cargos publicados. La reserva online puede ser adicional; WhatsApp: No evidenciado.
- Clínica: Manual documenta historia gráfica, periodontograma, recetas y tratamiento. Interoperabilidad radiográfica argentina: No evidenciado.
- Administración: Publica licencia/soporte y servicios. Integración fiscal argentina, obras sociales argentinas y medios de cobro locales: No evidenciado en las fuentes relevadas.
- Integraciones: Mercado Pago, Google Calendar, ARCA, API pública y WhatsApp: No evidenciado en esta muestra de fuentes.
- Seguridad y portabilidad: Permiso de bloqueos documentado. No se evaluaron cifrado, exportación, auditoría ni restauración; son No evidenciado en este relevamiento.

## Pricing

Otros países: USD89/mes por sede hasta 3 profesionales, contrato 12 meses; desde el cuarto, USD20/profesional según condiciones. Servicios web y conversión pueden costar aparte. Elegibilidad argentina final a confirmar.

## Posicionamiento

Self-hosted; cloud publicado para EE.UU. para consultorios y clínicas; referencia de dominio internacional. No se adopta el posicionamiento comercial como validación de resultados.

## Diferenciadores
